# Agent Instructions — dynamo-dotfiles

This file applies to this repository only. It overrides `dot_agents/AGENTS.md` where the two disagree.

## Commits and pull requests

- Commit to `main` and push to `origin/main`. This is the default procedure for each change.
- Pull requests are opt-in. Open a pull request or a working branch only when the user asks for one.
- The draft-PR policy in `dot_agents/AGENTS.md` does not apply to this repository.
